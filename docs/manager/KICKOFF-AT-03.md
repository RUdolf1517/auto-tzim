## Если кодер спросит «а точно Rust?»

Да. [D-33](DECISIONS.md), принято владельцем 2026-11-01. `SPEC.md` §4.1 всё ещё рекомендует Python и **не
редактируется** — приоритет у журнала решений и [CONFLICTS C-5](../spec/CONFLICTS.md).

## Если кодер спросит «почему без новых зависимостей, SHA-256 же есть в crates.io»

Потому что [D-52](DECISIONS.md) требует хеш, который ревьюер может пересчитать, а `sha2` тянет за собой `generic-array`,
`typenum`, `cpufeatures` и запись в allowlist — четыре причины для ревью ради 120 строк арифметики, у которых есть
официальные векторы. Это же правило уже действовало для файловой блокировки: `std`, а не крейт ([D-53](DECISIONS.md)).
